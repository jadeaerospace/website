# jadeaerospace.com

Public website for Jade Aerospace Limited (玉航天有限公司).

- `index.html` — English
- `zh/index.html` — Simplified Chinese
- `assets/style.css` — shared styles (Jade colours: jade #51BAC1, deep #1B7A80, peach #F6CDB4; fonts Space Grotesk + Manrope)
- `assets/` — images

Plain HTML, no build step. To edit: change the HTML in GitHub (pencil icon) or locally, commit to `main`, and Cloudflare Pages redeploys in about a minute. Keep the English and Chinese pages in step.

Don't put on this site: client names (NDAs), funding numbers, or anything about applications in progress.
